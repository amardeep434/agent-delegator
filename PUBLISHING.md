# Publishing Policy

This document defines what goes into the **Git repository** vs what gets **published to PyPI**.

## Git Repository

Everything needed for development, CI/CD, and project history.

| Category | Included | Rationale |
|----------|----------|-----------|
| Source code | ✅ `agent-delegator/*.py` | Core package |
| Templates | ✅ `agent-delegator/dashboard/templates/*.html` | Dashboard UI |
| Config | ✅ `agent-delegator/registry.json` | Default agent registry |
| Tests | ✅ `tests/*.py` | Regression testing |
| CI/CD | ✅ `.github/workflows/*.yml` | Automated testing & release |
| Release scripts | ✅ `.github/scripts/*.py` | Version bumping |
| Documentation | ✅ `README.md`, `INTEGRATION.md`, `AGENTS.md` | User & dev docs |
| Planning docs | ✅ `docs/plans/`, `docs/specs/` | Project decisions |
| Build config | ✅ `pyproject.toml`, `.gitignore`, `Makefile` | Packaging |
| License | ✅ `LICENSE` | MIT |

### Excluded from Git

| Category | Excluded | Rationale |
|----------|----------|-----------|
| Runtime state | ❌ `*.db`, `cooldowns.json`, `agent_*.log` | Generated at runtime |
| Local config | ❌ `.agent-delegator.json` | Per-project, user-specific |
| IDE configs | ❌ `.agent/`, `.claude/`, `.cursor/`, etc. | Personal preference |
| Build artifacts | ❌ `build/`, `dist/`, `*.egg-info/` | Generated by build |
| Session handoffs | ❌ `SESSION_HANDOFF.md`, `HANDOFF.md` | Temporary context |
| Mockups | ❌ `mockups/` | Design exploration |
| Backups | ❌ `*.backup`, `*.bak` | Generated files |
| Dev utilities | ❌ `sort_by_date.py`, `handoff-template.md` | One-off scripts |
| Prompt libraries | ❌ `.github/prompts/` | External skill data |
| OMC memory | ❌ `.omc/` | IDE session state |

## PyPI Package

Only what's needed to **install and run** the package.

### Wheel (`agent_delegator-*.whl`)

| Category | Included | Size |
|----------|----------|------|
| Source code | ✅ `agent-delegator/*.py` | ~60 KB |
| Templates | ✅ `agent-delegator/dashboard/templates/*.html` | ~83 KB |
| Config | ✅ `agent-delegator/registry.json` | ~6.5 KB |
| Metadata | ✅ `LICENSE`, `METADATA`, `WHEEL` | ~15 KB |

**Total wheel size: ~200 KB** (23 files)

### SDist (`agent_delegator-*.tar.gz`)

| Category | Included | Rationale |
|----------|----------|-----------|
| Source code | ✅ `agent-delegator/*.py` | For building from source |
| Templates | ✅ `agent-delegator/dashboard/templates/*.html` | Required for install |
| Config | ✅ `agent-delegator/registry.json` | Default registry |
| Tests | ✅ `tests/*.py` | Source verification |
| Documentation | ✅ `README.md`, `LICENSE` | Required by PyPI |
| Build config | ✅ `pyproject.toml` | For building |

**Total sdist size: ~250 KB**

### Excluded from PyPI

| Category | Excluded | Rationale |
|----------|----------|-----------|
| CI/CD workflows | ❌ `.github/workflows/` | Not needed at runtime |
| Release scripts | ❌ `.github/scripts/` | Internal tooling |
| Planning docs | ❌ `docs/plans/`, `docs/specs/` | Internal decisions |
| Integration guide | ❌ `INTEGRATION.md` | Available on GitHub |
| Agent instructions | ❌ `AGENTS.md` | Internal dev guide |
| Skills | ❌ `.claude/skills/` | Internal tooling |
| Hooks | ❌ `.claude/hookify.*.local.md` | Internal tooling |

## Verification

```bash
# Check what's in the wheel
python -m build --wheel
unzip -l dist/agent_delegator-*.whl

# Check what's in the sdist
python -m build --sdist
tar -tzf dist/agent_delegator-*.tar.gz

# Check what's tracked in git
git ls-files

# Check what would be ignored
git status --ignored
```

## Philosophy

- **Git repo** = Complete project history + development environment
- **PyPI wheel** = Minimal runtime package (fast install, small footprint)
- **PyPI sdist** = Full source for verification (includes tests)
- **Never** include runtime state, personal configs, or build artifacts in either
