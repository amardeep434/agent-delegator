Why agent-delegator?

Built for developers who use multiple AI agents and are tired of manual switching

Federated Failover

When Claude is down, automatically switch to OpenCode, Copilot, Codex, or Gemini. Circuit breaker tracks failures and applies smart cooldown.

Intelligent Routing

Code review goes to Claude. Implementation goes to OpenCode. 14 pre-configured routes across 4 workflows. Fully customizable.

Real-Time Dashboard

Local-only Mission Control at http://127.0.0.1:8765. Agent health, success rates, cost tracking, A/B comparison. No cloud. No signup.

Security First

XSS prevention, CSRF protection, rate limiting, SSRF checks, encrypted secrets. Every endpoint requires API key authentication.

Auto-Learning

Tracks success rates per agent and task type. Automatically optimizes provider priority order based on real performance data.

Zero Dependencies

Dashboard runs on pure Python stdlib. No Node.js, no React, no build step. Install with pip and go. Optional cryptography for encrypted secrets.
